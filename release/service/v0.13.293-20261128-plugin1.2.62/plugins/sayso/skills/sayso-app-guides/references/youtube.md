# YouTube

Visible landmarks: Search, player controls/CC, More, and Watch later under You/profile playlists.

1. Find/play: search requested title/keyword → verify title/channel → open matching result → check actual playback; an ad/loading state is not the requested video playing.
2. Captions: reveal player controls → CC → check subtitles; language selection is under Settings → Captions when available. State when captions are unavailable.
3. Watch later: list item's More → Save to Watch later, or player More → Save → Change → Watch later → check the saved result in playlists.

Do not add subscriptions, comments or purchases. Children's videos may not support Watch later.

Apply the [shared rules](../../sayso-control/references/workflows.md) and [App guide entrypoint](../SKILL.md).
