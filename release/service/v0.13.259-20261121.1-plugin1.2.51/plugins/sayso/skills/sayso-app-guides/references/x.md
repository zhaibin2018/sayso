# X / Twitter

位置：放大镜/Search 找帖子与账号；帖子详情有书签/Bookmark；个人头像的导航菜单可找 Bookmarks；信封/Messages 打开私信。

## 常见任务

1. **搜索帖子或账号**：Search → 输入英文关键词或 @handle → 选择 Latest/People 等结果类别 → 打开并核对作者及内容。
2. **保存书签**：打开指定帖子详情 → Bookmark 图标 → 看选中反馈；导航菜单 → Bookmarks 复查。若显示 Share → Add to Bookmarks，则先核对当前版本官方 iOS 帮助。
3. **准备私信**：Messages → 新建消息 → 输入并选中完整 @username → 追加指定英文正文 → 念出收件人和完整内容，等确认 → 停指针在纸飞机/Send，交用户点击。

## 注意

每一步看真实后图；界面不符或不会做先查官方帮助。第一版只能输入英文（ABC）。付款最后一步用户自己点；给别人发消息前念出收件人和完整内容，等确认；发送最后一步也交用户。不念、不输入验证码。对方隐私设置可能不允许私信，不反复提交；不顺带转帖、公开回复或购买 Premium。
