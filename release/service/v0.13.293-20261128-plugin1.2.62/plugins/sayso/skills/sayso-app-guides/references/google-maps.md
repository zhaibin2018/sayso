# Google Maps

Visible landmarks: search bar, place details with Directions/Save, travel modes, Start and You/lists.

1. Find a place: requested supported name/address → result → verify full address, city and pin; resolve duplicate names.
2. Navigate: destination → Directions → verify origin/destination → requested travel mode and route → Start → check navigation; Preview or unavailable GPS is not active navigation.
3. Save: place → Save → requested list → check state; review under You → Your lists.

Location/region affect availability. Do not add live-location sharing or reviews.

Apply the [shared rules](../../sayso-control/references/workflows.md) and [App guide entrypoint](../SKILL.md).
