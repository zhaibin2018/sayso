# Settings

Visible landmarks: Display & Brightness, Accessibility and the settings search field; positions vary by iOS version.

1. Enlarge text: Display & Brightness → Text Size → adjust the visible slider; if needed, Accessibility → Display & Text Size → Larger Text → Larger Accessibility Sizes, then adjust.
2. Brightness: Display & Brightness → Brightness slider → adjust as requested and check the result; avoid Auto-Lock.
3. Dark mode: Display & Brightness → Appearance → Dark or Light; if Automatic is on, scheduled settings may still change it.

Large text can obscure controls; relocate them from the current screen.

Apply the [shared rules](../../sayso-control/references/workflows.md) and [App guide entrypoint](../SKILL.md).
