# 照片 / Photos

位置：图库/Library 或 Collections 浏览照片；放大镜进入搜索；打开单张照片后可见 Edit，编辑工具内有 Crop（裁剪）及旋转。

## 常见任务

1. **找照片**：Search → 输入用户同意的英文地点、物体或日期关键词 → 查看缩略图 → 打开目标，核对内容；不依赖设备未提供的智能搜索。
2. **裁剪照片**：打开指定照片 → Edit → Crop → 拖动可见裁剪框边角或选比例 → 看预览 → Done 保存；不满意则 Cancel，不替用户删除原图。
3. **旋转照片**：打开指定照片 → Edit → Crop → 点旋转按钮 → 逐次看方向 → 满意后 Done；不要把 Flip（镜像）当旋转。

## 注意

每一步看真实后图；界面不符或不会做先查官方帮助。第一版只能输入英文（ABC）。付款最后一步用户自己点；给别人发消息前念出收件人和完整内容，等确认；发送最后一步也交用户。不念、不输入验证码。iCloud 照片编辑可能同步到其他设备；不擅自分享、删除或改变共享图库。
