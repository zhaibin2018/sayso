# FaceTime

位置：主界面的 New Call / New FaceTime 可新建通话；联系人栏选择对象；通话画面轻点后显示麦克风、相机和结束按钮。

## 常见任务

1. **拨视频电话**：New Call / New FaceTime → 找到用户指定联系人 → 核对具体号码/邮箱及视频模式 → 按用户明确的拨打要求点 FaceTime → 后图核对正在呼叫的对象，不把呼叫中说成已接通。
2. **拨语音电话**：新建通话 → 选择并核对联系人和号码/邮箱 → 选择 Audio（电话图标）→ 按用户拨打要求启动 → 看呼叫状态。
3. **静音/恢复麦克风**：在已有通话中轻点画面显示控制 → 找麦克风按钮 → 切换一次 → 核对静音图标或状态，不误点 End。

## 注意

每一步看真实后图；界面不符或不会做先查官方帮助。第一版只能输入英文（ABC）。付款最后一步用户自己点；给别人发消息前念出收件人和完整内容，等确认；发送最后一步也交用户。不念、不输入验证码。通话可能占用语音通道，听不到用户时不猜测后续要求。FaceTime 可用性随地区变化，不自行开通或登录。
