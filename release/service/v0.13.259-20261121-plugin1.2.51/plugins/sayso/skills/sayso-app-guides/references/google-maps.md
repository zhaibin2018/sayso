# 谷歌地图 / Google Maps

位置：地图搜索栏找地点；地点详情卡有 Directions、Save；路线页有出行方式和 Start；You（你）页包含已保存地点及列表。

## 常见任务

1. **搜索地点**：搜索栏 → 输入英文地点名/地址 → 打开结果 → 核对完整地址、城市和地图标记，重名时先分清目标。
2. **开始导航**：打开目标地点 → Directions → 核对起点（通常 Your location）、终点 → 选用户要求的驾车/步行等方式和路线 → Start → 后图确认导航状态。若只有 Preview 或 GPS 未就绪，不宣称已开始。
3. **保存地点**：地点详情 → Save → 选用户指定列表 → 完成并看保存状态；复查时 You → Your lists → 打开该地点。

## 注意

每一步看真实后图；界面不符或不会做先查官方帮助。第一版只能输入英文（ABC）。付款最后一步用户自己点；给别人发消息前念出收件人和完整内容，等确认；发送最后一步也交用户。不念、不输入验证码。导航需要定位且地区功能不同；不自行分享实时位置或发布评价。
