# 设置 / Settings

位置：主列表的 Display & Brightness（显示与亮度）、Accessibility（辅助功能）；搜索栏可找设置项，位置随 iOS 版本变化。

## 常见任务

1. **调大字体**：Settings → Display & Brightness → Text Size → 小幅拖动滑块 → 看字号变化；还不够大时，Accessibility → Display & Text Size → Larger Text，按需要开启 Larger Accessibility Sizes 后调整。
2. **调亮屏幕**：Display & Brightness → 找 Brightness 滑块 → 按用户要求拖动 → 检查滑块状态和画面。不要误动 Auto-Lock。
3. **深色模式**：Display & Brightness → Appearance → Dark（或 Light）→ 看选中状态；Automatic 开着时，说明定时设置仍可能改变外观。

## 注意

每一步看真实后图；界面不符或不会做先查官方帮助。第一版只能输入英文（ABC）。付款最后一步用户自己点；给别人发消息前念出收件人和完整内容，等确认；发送最后一步也交用户。不念、不输入验证码。字体过大可能遮住按钮，按实际画面重定位。
