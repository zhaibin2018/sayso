# WhatsApp

Visible landmarks: Chats search/new chat, recipient header, body, attachments and Send; navigation varies by version.

1. Message yourself: new chat → your own name/number (often marked You) → verify the current account's number → append the requested note → park on Send and leave the final tap to the user; a matching name alone is insufficient.
2. Find a chat/message: Chats search → supported contact/keyword → matching result → verify title/context; in-chat search is under the chat name.
3. Prepare another person's message: select exact account/number → append body → read back recipient/full content → wait for confirmation → park on Send for the user.

Preserve existing drafts. Self-chat cannot start a voice/video call. The previously readable self-message help was the Web version, so use the visible iPhone UI; consult official iPhone help only if the next step is unclear.
