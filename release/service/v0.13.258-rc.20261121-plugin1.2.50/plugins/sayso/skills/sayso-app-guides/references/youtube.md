# YouTube

位置：放大镜进入 Search；播放器轻点后出现播放与 CC 控件；视频旁 More 菜单可保存，Watch later 在 You/个人页的播放列表区域（旧版可能叫 Library）。

## 常见任务

1. **搜索并播放视频**：Search → 输入英文标题/关键词 → 核对标题与频道 → 打开指定结果 → 看播放器实际状态，广告或加载中不算正片已播放。
2. **开启字幕**：视频页 → 轻点播放器 → CC → 查看字幕；如需换语言，播放器 Settings → Captions → 选已有语言。没有 CC 时说明该视频未提供字幕。
3. **稍后观看**：浏览列表中找到指定视频 → 标题旁 More → Save to Watch later；或播放页 More → Save → Change → Watch later → 检查保存结果，在 You/个人页播放列表中查找。

## 注意

每一步看真实后图；界面不符或不会做先查官方帮助。第一版只能输入英文（ABC）。付款最后一步用户自己点；给别人发消息前念出收件人和完整内容，等确认；发送最后一步也交用户。不念、不输入验证码。不要把广告当目标视频；不顺带订阅、评论或购买，儿童内容可能不能加入稍后观看。
