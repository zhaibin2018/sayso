# Grab（新加坡 / Singapore）

位置：首页 Transport/Car 进入叫车；预订页有上车点、目的地、车型、费用和付款方式；Book/Confirm 是实际下单边界。

## 常见任务

1. **查到目的地的车费**：Transport → 核对上车地址 → 输入英文目的地并核对完整地址 → 查看车型列表、预计费用与接驾时间 → 读回结果，不点 Book。
2. **改预订前上车点**：叫车页 → 上车地址栏 → 搜索英文地址 → 选具体入口/接驾点 → Confirm 只确认地点 → 看返回页的上车点；若按钮会提交订单则停下。
3. **叫车到确认前停下**：按用户指定起终点准备路线 → 选车型 → 核对入口、目的地、人数/车型、费用和付款方式 → 停指针在最终 Book/Confirm 叫车按钮 → 后图确认后请用户自己点，不替用户叫车。

## 注意

每一步看真实后图；界面不符或不会做先查官方帮助。第一版只能输入英文（ABC）。付款和叫车下单最后一步用户自己点；给别人发消息前念出收件人和完整内容，等确认；发送最后一步也交用户。不念、不输入验证码。自动填入的 GPS 地址未必是正确入口；费用以屏幕报价为准，不擅自改支付设置、充值或取消已有订单。其他地区先查当地官方帮助。
