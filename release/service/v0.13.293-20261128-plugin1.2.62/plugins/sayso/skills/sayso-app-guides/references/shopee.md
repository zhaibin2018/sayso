# Shopee — Singapore

Visible landmarks: search, product options/quantity, Add to Cart/Buy Now, Cart, Check Out, order summary and Place Order/Pay.

1. Find a product: requested keyword → result → verify seller, variant, price and delivery; ad rank is not a quality conclusion.
2. Add to cart: Add to Cart → requested variant/quantity → verify price → Add to Cart → check cart item/options/count; do not select Buy Now.
3. Prepare checkout: select only requested items → Check Out only if it opens a summary → verify address, shipping, discounts, payment and total → park at the first Place Order/Pay button that commits → leave the tap to the user. Do not place an order merely to reach payment.

Do not add insurance or activate ShopeePay. Use local official help when a regional difference makes the next step unclear.
