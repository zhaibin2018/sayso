# Instagram

Visible landmarks: Search/Explore, post bookmark, profile menu/Saved and Messages; layout varies by version/region.

1. Find an account: Search → requested account → Accounts → verify full @handle, not display name alone.
2. Save a post: requested post → bookmark/Save → check state; review under profile → menu → Saved. Do not create collaborative collections or invite others.
3. Prepare a direct message: Messages → new message → exact @handle → Chat → append body → read back recipient/full content → wait for confirmation → leave Send to the user.

These routes were not verified against readable official help text on 2026-11-21 because of rate limits. Use only a clearly identifiable current control; consult official iPhone help if the next step is unclear, and stop if unresolved. Do not add follows, likes or accepting message requests.
