安装 SaySo

在 SaySo 点“连接 ChatGPT”，切到“工作”后发送预填消息。第一次会安装服务和插件；已装过会直接给连接链接。

安装完成后，ChatGPT 在同一对话给你连接链接。打开链接，点“生成连接”，再亲手点“回到 SaySo 完成连接”。不用回 App 再点第二个安装按钮；只切换 App 不会完成连接。

App Store 即将上线。以下固定候选已含新版流程，官网和发行包仍待推送／发布；完整手机安装和定期清理尚待真实验收。查看完整步骤。

Install SaySo

In SaySo, tap “Connect ChatGPT”, switch to Work and send the prefilled message. First use installs the service and plugin; an existing installation goes straight to a connection link.

ChatGPT returns the link in that same conversation. Open it, tap “Generate connection”, then personally tap “Return to SaySo to connect”. No second installation button is needed; switching apps alone does not finish connecting.

App Store release is coming soon. This pinned candidate includes the new flow but the website/package await publication. Complete iPhone installation and unattended cleanup still await real acceptance.
