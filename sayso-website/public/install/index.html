安装 SaySo

在 SaySo 点“连接 ChatGPT”，切到“工作”后发送预填消息。第一次会安装服务和插件；已装过会直接给连接链接。

服务和插件安装完成后，请回到 SaySo 再点一次“连接 ChatGPT”，在新的“工作”对话发送（约 2 分钟后可用）。取得连接链接后，点“生成连接”，再亲手点“回到 SaySo 完成连接”。

App Store 即将上线。以下固定发行包已发布；完整手机安装和定期清理尚待真实验收。查看完整步骤。

Install SaySo

In SaySo, tap “Connect ChatGPT”, switch to Work and send the prefilled message. First use installs the service and plugin; an existing installation goes straight to a connection link.

After installation, return to SaySo, tap “Connect ChatGPT” again and send in a new Work conversation (available in about 2 minutes). Open the returned link, tap “Generate connection”, then personally tap “Return to SaySo to connect”.

App Store release is coming soon. This pinned service package is published. Complete iPhone installation and unattended cleanup still await real acceptance.
