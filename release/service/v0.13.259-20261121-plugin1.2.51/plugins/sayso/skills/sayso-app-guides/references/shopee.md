# Shopee（新加坡 / Singapore）

位置：首页搜索栏找商品；商品页有规格、数量、Add to Cart 和 Buy Now；购物车图标进入 Cart；Me 内可找 My Purchases。Check Out 后有订单汇总及 Place Order。

## 常见任务

1. **搜索商品**：搜索栏 → 输入英文商品词 → 查看结果 → 打开指定商品 → 核对卖家、规格、价格及配送范围，不把广告排序当质量结论。
2. **加入购物车**：商品页 Add to Cart → 选择用户指定规格及数量 → 核对价格 → Add to Cart → 看成功提示，进入 Cart 核对商品、规格与数量；不点 Buy Now。
3. **到付款前停下**：Cart → 只勾选用户指定商品 → Check Out（仅进入汇总）→ 核对地址、运费、优惠、付款方式和总额 → 停在最早会下单/扣款的 Place Order/Pay 按钮 → 后图确认后请用户自己点，不为到达付款页先下单。

## 注意

每一步看真实后图；界面不符或不会做先查官方帮助。第一版只能输入英文（ABC）。付款和下单最后一步用户自己点；给别人发消息前念出收件人和完整内容，等确认；发送最后一步也交用户。不念、不输入验证码。密码、支付资料由用户自己输入；不擅自选附加保险或开通 ShopeePay。其他地区先查当地官方帮助。
