# Photos

Visible landmarks: Library/Collections, Search, Edit and Crop controls.

1. Find a photo: search with a user-approved supported place/object/date keyword → inspect thumbnails → open and verify the target; do not assume unavailable intelligent search.
2. Crop: requested photo → Edit → Crop → move visible crop handles or select aspect → check preview → Done; use Cancel if unwanted and do not delete the original.
3. Rotate: Edit → Crop → rotate one step at a time → check orientation → Done; distinguish Flip from Rotate.

iCloud edits may sync to other devices. Do not add sharing, deletion or shared-library changes to the request.

Apply the [shared rules](../../sayso-control/references/workflows.md) and [App guide entrypoint](../SKILL.md).
