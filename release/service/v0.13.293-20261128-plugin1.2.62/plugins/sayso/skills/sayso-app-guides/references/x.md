# X / Twitter

Visible landmarks: Search, post Bookmark, navigation menu/Bookmarks and Messages.

1. Search: requested keyword/@handle → appropriate Latest/People category → verify author/content.
2. Bookmark: requested post → Bookmark → check state → menu → Bookmarks to review. If the control differs, use the visible UI and consult official iOS help only when the next step is unclear.
3. Prepare a direct message: Messages → new message → exact @username → append body → read back recipient/full content → wait for confirmation → leave Send to the user.

Recipient privacy settings can block messages; do not repeatedly submit. Do not add reposting, public replies or Premium purchases.

Apply the [shared rules](../../sayso-control/references/workflows.md) and [App guide entrypoint](../SKILL.md).
