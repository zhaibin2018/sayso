# FaceTime

Visible landmarks: New Call/New FaceTime, contact selection and in-call microphone, camera and End controls.

1. Video call: New Call → find the requested contact → verify exact number/email and video mode → start only on the user's explicit calling request → distinguish ringing from connected.
2. Audio call: choose and verify recipient/number → Audio/phone icon → start the requested call → check status.
3. Mute/unmute: reveal current call controls → toggle the microphone once → check the state without hitting End.

Calls may occupy the voice channel; do not infer further instructions when the user cannot be heard. Availability varies by region; do not activate or sign in without a request.

Apply the [shared rules](../../sayso-control/references/workflows.md) and [App guide entrypoint](../SKILL.md).
